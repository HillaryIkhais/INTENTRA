Step 02 — Delegate

Agent creates a child

Your agent wants to delegate execution to a child. INTENTRA verifies the child's authority is a subset of the parent's.

The invariant:
Child ≤ Parent

If the child tries to ask for more than the parent has → BLOCKED.

This is the core of INTENTRA. No agent can escalate authority beyond what was granted.
