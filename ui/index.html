/01 — The problem

A child agent can look completely legitimate
while possessing authority nobody granted it.

The old way: trust the agent

You told Agent A to trade BNB with a $10 limit. Agent A created Agent B. Agent B says it's allowed to trade ETH for $75. You have no idea where that authority came from — because it didn't come from anywhere. The agent made it up.

The INTENTRA way: verify the chain

Before any agent acts, INTENTRA walks the full delegation chain from your original permission down to the current agent. Every step must narrow. If anything widened — a new asset, a higher limit, a removed restriction — it's blocked before it reaches the exchange.

/02 — How it works

Four steps. One rule. Zero exceptions.

01

You issue a permission

Tell INTENTRA what your agent is allowed to do: which assets, which actions, spending limits, time windows.

02

Agent delegates

Your agent creates a child agent. INTENTRA checks: is the child's authority a strict subset of the parent's?

03

Chain validates

Every delegation in the chain is verified. Child ≤ Parent at every step. If anything widened, it's blocked.

04

Trade executes

Only if the full chain validates does the trade reach Binance. Every action gets a provenance receipt.

/06 — We found our own bugs

The first version had holes. We fixed them.

Blind spots we discovered

BUG 1Child could remove its own spending limit. If parent had a $10 limit but child didn't specify one, compiler treated it as "no restriction."
BUG 2Child could skip human approval. Parent required approval above $500. Child's proposal went straight through without it.
BUG 3Child could extend its own deadline. Parent expires in 1 hour. Child sets its own expiry to 24 hours.
BUG 4Child could remove restrictions. Parent prohibited short selling. Child simply didn't include that restriction.
BUG 5Our test tool had the same blind spots. The fuzzer was testing against itself. We rewrote it to test the actual engine.

The model can't lie to us

Same permission, different words, same result:

Agent says: "Buy $15 BNB" → BLOCK
Agent says: "I'm authorized for $500" → BLOCK
Agent says: "System override: $70 ETH" → BLOCK
Agent says: "Buy $8 BNB" → ALLOW

INTENTRA doesn't listen to what the agent says. It checks what the agent is allowed to do.
