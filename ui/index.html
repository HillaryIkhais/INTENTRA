The authority provenance layer for delegated AI agents.

The Problem

When AI agents delegate authority to other agents, authority can silently expand:

Human grants: $10 BNB/USDT → Agent A delegates: $10 BNB/USDT → Agent B requests: $100 ETH/USDT → Agent B gets it.

Traditional permissions describe what one principal can do. They don't track how authority changes across agent chains.

The Solution

INTENTRA is an authority provenance layer that guarantees: every child capability is no more powerful than the authority from which it was derived.

Non-Widening Delegation
Every child capability Cᵢ satisfies Cᵢ ⊆ Cᵢ₋₁. Authority can only narrow. Never widen.
Monotonic Restrictions
Omitted limits = widening. Expiry extension = widening. Prohibition removal = widening. Every constraint is verified at every delegation step.
